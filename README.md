# PXL UI

**Low-Res Look, High-Res Craft.**

Pixel-style React components for widgets, small screens, and interfaces with a little character. Sharp edges, bitmap type, and playful details paired with modern interactions.

[Explore the demos](https://pxl-ui.github.io/registry/) · [Get started](https://pxl-ui.github.io/registry/docs/installation/) · [Browse components](https://pxl-ui.github.io/registry/components/)

## Small screens. Plenty of personality.

Build a weather widget, a reading shelf, a conversation, or a dashboard that feels like a tiny desktop. Start with individual controls or combine them into something larger.

PXL UI brings the visual pieces together:

- **Pixel components.** Buttons, inputs, cards, menus, dialogs, and navigation with pixel borders and themeable colors.
- **Ready to compose.** Conversation bubbles, library shelves, newspaper layouts, task boards, and weather views.
- **Compact widgets.** Day views and quest logs for interfaces where every pixel counts.
- **A complete visual vocabulary.** Bitmap fonts, retro palettes, icons, cursors, animated backgrounds, and sprite utilities.
- **Room for real content.** Rich text editing, media controls, and schemas and adapters for feeds, books, recipes, and more.

Built with React 19, Tailwind CSS 4, and Base UI, with TypeScript throughout. Explore the [documentation](https://pxl-ui.github.io/registry/) for interactive previews, variants, and usage examples.

## Make it yours

PXL UI is a shadcn registry. Install the source into your project, then change the styles, behavior, and composition to suit what you are building.

Browse the registry:

```sh
pnpm dlx shadcn@latest list pxl-ui/registry
```

Add a component:

```sh
pnpm dlx shadcn@latest add pxl-ui/registry/button
```

Prefer npm? Use `npx shadcn@latest` instead of `pnpm dlx shadcn@latest`.

See the [installation guide](https://pxl-ui.github.io/registry/docs/installation/) and the component's documentation for styles, fonts, and dependencies. Each component page also includes source code for manual installation.
