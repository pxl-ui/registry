## Gradients

## Palettes

The PXL UI registry provides some color palettes you can install and include into your projects.

### Complete Palettes

These palettes are focused on providing an entire set of colors to cover most use cases.


<div class="not-content grid sm:grid-cols-2 gap-2.5">

  {lists.complete.map(item => (
    <LinkCard 
      href={routeFromRegistryItem(item.name, "colors")} 
      title={item.title ?? item.name}
      description={item.description}
    >
      {palettes.has(itemBasename(item.name, "colors")) && (
        <ColorWheel slot="avatar" palette={palettes.get(itemBasename(item.name, "colors"))} />
      )}
    </LinkCard>
  ))}

</div>
