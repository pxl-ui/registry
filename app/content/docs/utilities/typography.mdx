PXL-UI provides fonts for `font-heading`, `font-sans`, and `font-mono`.

Please note that each fonts may require different methods of installation or downloading typographic resources.

## Heading Fonts

Default value: <a href={url("fonts/pixel-digivolve")}>Pixel Digivolve</a>

These fonts are useful for displaying titles, headings, or funcy badges and buttons (normally in uppercase).
