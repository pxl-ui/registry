## Base

PXL-UI Base includes a monochromatic theme by default. Additional bases and color palettes can be installed from the [registry](#palettes).

5 different color variants are available in some components to express intentionality.

## Gradients

PXL-UI includes predefined gradients inspired by various video game indicators.

The gradients are defined as `--background-image` variables in TailwindCSS, so they can be easily used with `bg-{{gradient_name}}` classes.

A common use case is to use them to decorate texts.

<div class="not-content">
  <p class="font-mono text-base font-bold whitespace-nowrap bg-clip-text text-transparent pixel-drop-foreground pixel-size-md bg-loot">+150 XP</p>
</div>

## Palettes

The PXL UI registry provides some color palettes you can install and include into your projects.
