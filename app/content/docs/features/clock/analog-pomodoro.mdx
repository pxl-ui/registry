## Props

| Prop | Type | Description |
| --- | --- | --- |
| `size` | `sm \| default \| md \| lg` | Watch size. |
| `variant` | `default \| primary \| secondary \| outline` | Semantic case colors. |
| `border` | `solid \| rounded \| none` | Beveled, outlined, stepped or plain case. |
| `className` | `string` | Root customization. |
| `autoStart` | `boolean` | Start on mount; default `false`. |
| `disabled` | `boolean` | Freeze time and disable controls. |
| `focusDuration` | `number` | Seconds; default `1500`. |
| `shortBreakDuration` | `number` | Seconds; default `300`. |
| `longBreakDuration` | `number` | Seconds; default `900`. |
| `sessionsBeforeLongBreak` | `number` | Focus sessions per long break; default `4`. |
| `autoAdvance` | `boolean` | Start the next phase automatically; default `false`. |
| `onPhaseChange` | `(phase, completedSessions) => void` | Called on completion, Skip and Reset. |
Each component is contained in one file. Pixel shapes use the registry's styles and semantic theme tokens. Internal elements expose `data-slot`; controls are small, unlabeled physical pushers attached directly to the watch bezel, with accessible names and native tooltips, using the registry Button with Base UI keyboard behavior. Only the watch and its pushers are visible; time and phase readouts are available to screen readers. Timer updates are not announced every tick; completion and phase changes have a separate status region. All instruments accept native div props, including accessible labels.
