PXL-UI provides fonts for `font-heading`, `font-sans`, and `font-mono`.

Please note that each fonts may require different methods of installation or downloading typographic resources.

## Heading Fonts
> These fonts are useful for displaying titles, headings, or fancy badges and buttons (normally in uppercase).

<div class="not-content mt-8 grid grid-cols-2 gap-4 md:grid-cols-3">

  {lists.headings.map(item => (
    <LinkCard
      href={toRouteId(item.name)}
      title={item.title ?? item.name}
      description={item.description}
    >
      <LinkCardMedia
        slot="avatar"
        item={item.name}        
      />
    </LinkCard>
  ))}

</div>
